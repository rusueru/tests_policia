# tests_policia

Plataforma personal de tests para Policía Local.

## Estructura
- `index.html`: portada y listado de temas.
- `test.html`: motor común.
- `css/styles.css`: diseño.
- `js/app.js`: lógica de los tests.
- `js/progreso.js`: progreso guardado en el navegador.
- `temas/tema05.js`: preguntas del Tema 5.
